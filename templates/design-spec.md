# Design Spec（每次任务必须先填这张表）

## 二、示例（填好的版本）

```markdown
# Design Spec · 衡石铸件质检平台（营销页）

## 0. 参考声明
参考 1：Stripe —— 借鉴「规格条用细线 + 真数字、表格感」的手法
参考 2：Linear —— 借鉴「1px 低对比描边 + 单一强调色 + 高信息密度」的手法
不借鉴：Stripe 的蓝紫渐变、Linear 的深色紫调与具体栅格

## 1. 情绪
冷静 → 暖纸底 #F4F2ED、无渐变、全站 1px 描边
精密 → 8pt 网格、数字等宽、圆角 ≤14
克制 → 强调色仅深绿 #14543F，面积 <8%；动效最长 420ms；无装饰插画

## 2. 色彩
--primary:#14543F（主按钮、关键数字、链接）
--accent:#B4451F（仅"缺陷/告警"，一屏 ≤2 处）
--n-50:#F8F6F2 --n-100:#F1EEE8 --n-200:#E4DFD6 --n-300:#CFC8BC
--n-400:#A39C90 --n-500:#7A746A --n-600:#5A554D --n-700:#3E3A34
--n-800:#26231F --n-900:#14171C --n-950:#0F1114
主色面积 ≤8%｜正文 16.1:1｜大字 7.8:1
明暗两套：是｜深色底 #0F1114｜深色字 #EDEAE3

## 3. 字体
展示：宋体（Songti SC / Noto Serif SC）—— 工业品需要"材质感与年代感"，衬线承担语气
正文：系统无衬线（PingFang SC / Microsoft YaHei）—— 保证 16px 下的扫描效率
字阶（1.25）：13 / 16 / 20 / 25 / 31 / 39 / 49
行高：标题 1.02（全大写场景 ≥1.0）｜正文 1.7
字距：展示 -0.035em｜正文 0
行宽：34ch（中文）｜中文：中英分别声明，数字 tabular-nums，单位小一号

## 4. 间距
4 图标-文字｜8 行内｜12 字段｜16 卡内紧凑｜24 卡内默认｜32 卡间距
48 移动区块｜64 桌面区块｜96 hero 留白
密度档：宽松（营销页，单屏一个主张）

## 5. 圆角
8 按钮｜12 卡片｜20 弹层（本页未用弹层，保留定义）

## 6. 阴影
shadow-1 卡片｜shadow-2 hover｜shadow-3 深色面板内高光
深色模式：1px rgba(255,255,255,.10) 描边替代阴影

## 7. 网格
断点 640/1024/1440｜列 12/8/4｜沟槽 32/24/16｜页边距 64/48/24
最大内容宽：1180px（营销但偏产品，取 1200 以下）

## 8. 动效
时长：120 按压｜180 hover｜240 展开｜320 视图｜420 入场编排
缓动：cubic-bezier(.22,1,.36,1)；退出 cubic-bezier(.4,0,1,1)
位移：12/16/24｜stagger 60ms（主标题 0、说明 +60、证据卡 +120）
降级：扫描线隐藏、标注常显、入场直接显示

## 9. 结构与签名
版式模板：编辑式大字（主）+ 分屏叙事（论证段）
焦点：h1「每一件铸件，都过一遍光」49px 衬线，靠尺寸 + 字族对比 + 孤立
非对称：hero 1.35fr / 1fr；论证段 1.15fr / 0.85fr
签名元素：扫描线只在 hero 扫一次（服务"检测"这一信息），其余区域全静止

## 10. 状态与降级
交互组件 6 个（导航链接、主/次按钮、重播、CTA）—— 8 态齐全：是
加载：无异步区块（静态页）；空态/错误态：表单类页面另出
```
