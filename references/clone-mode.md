# 模式 B：参考图 / 目标网站 → 复刻提示词（完整流程）

参考方法论：`JCodesMore/ai-website-cloner-template`（Map → Observe → Build → Compare）+ taste-skill 的真实素材纪律。

## 路径选择

| 条件 | 路径 |
|---|---|
| Agent 有浏览器权限（Playwright/Chrome） | B-1 完整复刻（像素级） |
| 只有截图 / 用户贴图 | B-2 读图复刻（骨架级） |
| 目标站有设计系统文件 | B-3 直接读 token（最准） |

---

## B-1 浏览器路径（像素级复刻）

### 步骤 1 · Map（建地图）
- 目标 URL → 本地路由映射表（一页一清）
- 记录：页面清单、导航结构、全局行为（平滑滚动？固定头？暗色模式？）

### 步骤 2 · Observe（观察取样）
对每个页面，桌面 + 移动两种宽度：
- `getComputedStyle` 读取并落表：
  ```
  色板：bg / surface / text-primary / text-secondary / accent / border
  字体：family / h1 / h2 / body / caption 的 size·weight·line-height·letter-spacing
  形状：圆角 sm/md/lg、阴影 0/1/2 级的 blur·spread·color
  间距：区块垂直节奏（如 96/128/160px）、栅格列数、断点值
  ```
- 资产：下载真实图片/字体/SVG/视频清单（记来源与许可）
- 状态取样：hover / active / focus / open / empty / loading 各截图一张
- **每个观察值都是规则的样本**：同一个属性在 3 处取样取规律，不是抄第一个值

### 步骤 3 · 组件规格文档
按区块输出（每个区块一页）：
```
## 区块：Hero
结构：左文右图 / 上文下图 / 全屏视频 …
令牌：引用 Observe 的 token 表（{colors.accent} 语法）
状态：default / hover / mobile 的差异
内容：真实文案（从源站提取后替换为自己的）
```

### 步骤 4 · Build（生成）
- 用步骤 2/3 的产物写代码，不凭记忆写"差不多"
- 独立区块可并行生成，但共享同一 token 表
- 输出 Next.js+Tailwind（工程交付）或单文件 HTML（快速预览）按用户需要

### 步骤 5 · Compare（像素 Diff 自检）
- 同尺寸（如 1440×900 / 390×844）截图源页与生成页
- 列差异清单，按"结构 > 层级 > 配色 > 间距 > 动效"优先级修
- 每轮修 top 3，最多 3 轮
- 验收：同尺寸下布局骨架、视觉层级、留白节奏对齐；允许字体渲染级差异

## B-2 截图路径（读图复刻）

没有浏览器时，把截图当"规则的样本"读：

### 步骤 1 · 5 行式解剖（`prompt-anatomy.md`）
- 第 1 行定风格名（从风格库匹配或新造）
- 第 2-4 行从图里**读出**：背景什么色、强调色用在哪、标题/正文字号比、圆角大小、阴影轻重、留白尺度

### 步骤 2 · 目测取样 token 表
```
主色 #______（从最大面积的非背景色取）
背景 #______ / 卡片面 #______
文字 主 #______ 次 #______
标题:正文 字号比 ≈ ____ : 1（目测 3:1 以上为佳）
圆角 ____px / 阴影 ____（轻/中/重）
区块留白节奏 ____px
```

### 步骤 3 · 写复刻提示词（结构）
```
1. 角色 + "已通读反 slop 规则"
2. 风格段（步骤 1 的 5 行，含精确色值）
3. 目测 token 表（步骤 2）
4. 区块清单：从截图按视觉顺序列（左→右、上→下）
5. 自检要求："生成后与参考图并排比对：布局骨架/视觉层级/留白节奏三项对齐"
6. 平台段 + 动效段 + 输出要求（同模式 A5-A6）
```

### 步骤 4 · 比对验收
并排看三样：**布局骨架、视觉层级、留白节奏**。三项对齐即合格复刻；像素级差异留给浏览器路径。

## B-3 设计系统文件路径
目标项目有 DESIGN.md / Tailwind config / tokens.json：直接读文件，跳过目测，token 表 100% 准确，然后走 B-1 步骤 3-5。

## 红线（复刻的纪律）

- 复刻**方法**，不搬运**资产**：logo、原创文案、授权图片必须替换为自己的
- 遵守目标站点服务条款；禁止用于钓鱼/仿冒/假冒他人设计
- 用户要求"复刻"时默认理解为"学习其设计与实现方式"
