# UI 设计要素体系与提示词框架（主规范）

本文件是全技能的**主规范**：把"好看"翻译成 AI 能直接执行的参数。
分析样本：4 张营销页参考图 + 6 张电商数据工作台 + 6 张自媒体创作工作台 + 6 张医疗工作台（共 22 张）。

---

# 第一部分 · 八要素分析框架

任何界面都按这八项拆解。提示词缺任何一项，AI 都会自由发挥（= 生成默认脸）。

## 要素 1 · 整体布局结构

**术语体系（写给 AI 的）**

## 要素 3 · 排版节奏

**字号层级（六档，全系统通用）**

| 层级 | 字号 | 字重 | 行高 | 颜色 | 用途 |
|---|---|---|---|---|---|
| Display | 26-28px | 700-750 | 1.3 | #1A1D26 | 页面/Hero 标题 |
| H2 | 15-16px | 650-700 | 1.4 | #1A1D26 | 卡片标题 |
| Body | 13.5-14px | 400-500 | 1.6 | #3D4453 | 正文、列表主文 |
| Label | 13px | 500 | 1.5 | #8A90A2 | 表单标签、KPI 标签 |
| Meta | 11.5-12.5px | 400 | 1.5 | #8A90A2 / #B6BCCB | 时间、说明、单位 |
| Badge | 11px | 600 | 1.2 | 语义色 | 状态、标签 |

**节奏规则**
- 字号跨度 ≥ 3 倍（28 / 16 / 13 即达标）；同级只用一档字号，不出现 17px、19px 这种"手感值"
- 间距走 4/8pt 网格：卡内 padding 18-20、卡片 gap 16、区块 gap 16-20、页面 padding 24
- 行高：标题 1.3、正文 1.6、元信息 1.5
- 数字全部 `font-variant-numeric: tabular-nums` + 千分位；中文标题 `letter-spacing: -0.01em`

## 要素 4 · 配色方案

**三套系统共用一套骨架，只换主色**

```
背景   #F5F7FB / #F6F7FB（浅灰蓝，不用纯白，让白卡片浮起来）
卡片   #FFFFFF
描边   #ECEEF3（1px，代替阴影做分隔）
阴影   0 1px 2px rgba(26,29,38,.03), 0 4px 16px rgba(26,29,38,.05)  ← 极软，双层
主文字 #1A1D26 / 次 #8A90A2 / 弱 #B6BCCB
主色   医疗 #2E7CF6 / 电商 #3B7CF6 / 创作 #4E6EF2（蓝系，饱和度 90%+）
语义   成功 #22B07D / 警告 #FF9A3D / 危险 #F04438 / 信息 = 主色
AI 专属 渐变 #7B5CFA → #5B8DEF + sparkle 图标（贯穿全部系统）
平台色 抖音#161823 小红书#FF2442 B站#FB7299 视频号#07C160
```

**配色纪律**
1. 一屏最多 1 个主色 + 4 个语义色 + 中性阶；语义色只以 **12% 透明度软底**出现，不做大面积实色
2. 强调色使用面积 < 5%（主按钮、激活导航、关键数字）
3. 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1
4. 趋势色二选一（金融红涨绿跌 / 通用绿涨红跌），全站统一，禁止混用

## 要素 5 · 图标风格

| 层级 | 规格 |
|---|---|
| 导航图标 | 线性 2px 描边、圆角端点、18-20px、颜色跟文字（激活=主色） |
| 模块图标 | 40px 软底方块（radius 12，色值 10-14%）内嵌 18-20px 同色实心/双色图标 |
| 快捷操作 | 40px 渐变方块（蓝/紫/绿/橙各一）+ 白色线性图标 |
| 文件类型 | 文档蓝 / 图片绿 / 视频紫 / 音频橙，统一软底 |
| AI 标识 | 四角 sparkle（✦）+ 渐变，只给 AI 功能用 |

**铁律**：全站一套图标库（Lucide / Tabler 风格），SVG 内联；**禁用 emoji**；同类图标线宽一致；不带阴影和描边重影。

## 要素 6 · 字体与颜色（字体族）

- 中文：PingFang SC / HarmonyOS Sans / 思源黑体；英文数字：Inter / SF Pro
- 数字必须开启等宽数字（tabular-nums），金额带 ¥ 前缀、千分位
- 一个界面最多 2 个字体族；标题与正文同族不同字重即可
- 不用细体（300 以下）做正文；不用斜体做中文长文本

## 要素 7 · 背景图片运用

| 场景 | 用法 |
|---|---|
| 后台 Hero 横幅 | 渐变底（浅蓝）+ 右侧 3D 吉祥物（180-220px，PNG 透明）+ 柔和光斑/植物插画；文字区永远在左，插画永远在右 |
| 营销页 Hero | 大图实拍/产品渲染，占屏 ≥ 60%，文字叠加区加 scrim（0-40% 黑或白色渐变遮罩） |
| 卡片缩略图 | 62-64px，`object-fit: cover`，圆角 8px，右下角压时长/数量徽章 |
| 头像 | 40px 圆形，照片或首字软底；列表内统一尺寸 |
| 禁止 | 后台大面积照片背景、满屏玻璃模糊、多彩渐变堆叠、装饰性插图抢占信息区 |

## 要素 8 · 交互动画与呼吸感

> 静态截图无法确认原始动效，以下为同类产品的实测惯例 + 本规范推荐值。

**动效时间轴（统一）**

| 类型 | 参数 |
|---|---|
| 入场 | 区块 opacity 0→1 + translateY 12-16px，0.4s，`power3.out`，stagger 0.05-0.06 |
| 悬停 | 卡片 `translateY(-2~-3px)` + 阴影加深，0.2s；列表行背景 #F8FAFC，0.15s |
| 按下 | `scale(.97)`，0.12s |
| 数字 | count-up 1.2s，进入视口触发一次 |
| 柱状图 | 从 0 基线生长 0.6-0.8s，柱间 stagger 0.03 |
| 折线图 | `stroke-dashoffset` 描绘 1s，面积渐变淡入 0.4s 延迟 |
| 页面切换 | 淡入 0.25s，禁止横向滑动过场 |
| 骨架屏 | shimmer 1.5s 循环 |

**呼吸感（Breathing）——只给"活的"元素**
- AI 吉祥物 / AI 渐变按钮：6-8s 循环，`scale 1→1.02` 或外发光 opacity 0.4→0.7
- 紧急徽章（逾期/紧急/缺货）：圆点 pulse 2s，`scale 1→1.6 + opacity 1→0`
- 实时数据点：末端圆点呼吸 2.5s
- **数量限制**：一屏最多 2 个呼吸元素；禁止全屏漂浮、禁止装饰动画抢注意力
- 必须提供 `prefers-reduced-motion: reduce` 全量降级（动画归零，内容直接可见）
- 只动 `transform / opacity / filter`，禁止动 `width/height/top/left`

**兜底铁律（血泪教训）**：内容默认可见。禁止用 CSS 预先 `.anim{opacity:0}` 隐藏，
再靠 JS 显示——一旦 GSAP CDN 加载失败，整页会变成"只有外壳的空白页"。
正确做法：不写预隐藏，交给 `gsap.from()` 自己设初始态，守卫 `if(!window.gsap) return;`。
交付前用 `scripts/preflight.py` 检查 E1 项。

## 要素 9 · 四个设计旋钮（整合自 ui-craft）

写提示词前先声明，AI 才知道"做到什么程度算完成"：

```
CRAFT_LEVEL      = 7   精修深度   3 快出 · 9 像素级
MOTION_INTENSITY = 5   动效强度   1 只 hover · 10 滚动叙事
VISUAL_DENSITY   = 5   信息密度   1 编辑式留白 · 10 仪表盘密集
DESIGN_VARIANCE  = 7   版式胆量   1 对称安全 · 10 实验构图（后台默认 4 / 落地页 7 / 作品集 8）
```

行为带：
- `MOTION ≤3` 只 hover；`4-7` 入场+悬停，每屏 ≤1 个滚动揭示；`8+` 滚动联动/转场/磁性光标
- `DENSITY ≤3` 每行 1-2 项；`≥8` 仪表盘密集
- `VARIANCE ≤4` 对称栅格；`5-7` 分栏 hero + 一处破格；`≥8` 展示级（仅用户要求时）
- `CRAFT ≥8` 追加打磨轮（Polish Pass）；`≤4` 跳过

这是让提示词"专业且精准"的核心：AI 听不懂形容词，但听得懂参数。
