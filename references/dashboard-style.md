# 仪表盘 / 工作台 UI 提示词规范（B 端页面专用）

来源：对 6 张"AI 电商工作台"后台截图的拆解。工作台与营销页是两种生物：
营销页卖"感受"，工作台卖"效率"——**信息密度高、组件复用、状态语义化、数字可扫读**。

---

## 一、布局骨架（先定骨架再填内容）

```
┌──────────┬────────────────────────────────────────┐
│ Logo     │  搜索框(居中胶囊)            头像+姓名+角色 │
│ ───      ├────────────────────────────────────────┤
│ 分组导航   │  页面标题 22-24px 粗 + 灰色副标题            │
│ 图标+文字  │  ┌──┐┌──┐┌──┐┌──┐  KPI 卡行(4列)          │
│ 激活=蓝底  │  └──┘└──┘└──┘└──┘                          │
│          │  图表区(2/3 + 1/3 或 1/2 + 1/2)            │
│ ───      │  表格区(筛选行 + 表头 + 行 + 分页)            │
│ 升级卡片   │                                          │
└──────────┴────────────────────────────────────────┘
```

- 侧边栏 200-220px 固定，图标 + 文字导航，**激活项 = 主色 10% 软底 + 主色文字**；底部可固定运营卡片（升级/配额）
- 内容区间距 20-24px，卡片间距 16px
- 页面标题区固定三段式：大标题 + 一句话副标题 +（可选）右侧主按钮

## 二、KPI 卡解剖（工作台的第一组件）

```
┌────────────────────────┐
│ [彩色软底图标 38px]       │  ← 圆角 10-12px 软底(主色10-15%) + 同色线性图标
│ 可售库存        13px 灰  │
│ 12,560  28px 粗 tabular │  ← 数字永远 tabular-nums、千分位
│ ↑ 5.3%  较昨日 +630     │  ← 涨红跌绿(中国惯例)；"较昨日"12px 灰
└────────────────────────┘
```

**铁律**：
- 数字是绝对主角：26-30px、700 字重、等宽数字、千分位分隔
- 趋势色遵守中国股市惯例：**涨 ↑ 红、跌 ↓ 绿**（欧美工具反过来，别抄错）
- 图标 chip 颜色按语义分配（库存蓝/预警橙/销售绿/利润紫），同屏不重复用同一色
- 软底 = 色值 10-15% 透明度，不是纯色块

## 三、色彩系统（从截图提炼）

```
主色(蓝)   #3B7CF6 一族   导航激活/主按钮/链接/图表主线
AI 专属    紫渐变 #7C5CFC→#5B8EF4 + 机器人图标   ← AI 功能必须有独立视觉身份
语义色     成功 #34A853 / 警告 #F5A623 / 危险 #F04438 / 信息 #3B7CF6
中性阶     背景 #F5F7FA / 卡片 #FFFFFF / 分隔 #EEF0F4 / 主文字 #1F2329 / 次文字 #8A919F
```

- 语义色全部走"软底徽章"（bg 12% + 深色文字），**禁用大面积纯色块**
- AI 相关功能（助手、文案、策划、分析）统一紫色渐变 + 机器人/星星图标，是这套设计最聪明的记忆点

## 四、组件规范

**分段 Tabs**：`近7天 | 近30天 | 近90天 | 自定义`，激活 = 白底胶囊 + 轻阴影，或主色文字 + 底部 2px 指示条

**状态徽章**：软底圆角 6px，12px 字
`已完成`绿 / `待审核`橙 / `进行中`蓝 / `异常`红 / `无需补货`灰绿 / `建议补货`橙

**表格**：
- 行高 48-56px，浅色行分隔线（禁斑马纹）
- 筛选行 = 搜索框 + 下拉 + tabs + 右侧主按钮（"新建/导出"）
- 操作列 = 文字链接 + "更多"下拉
- 分页 = 总数 + 页码胶囊 + 每页条数下拉

**图表**：
- 折线：2-3px 圆角粗线 + 同色渐变面积填充，网格虚线 #EEF0F4
- 环形图：中心大数字 + 总计标签，图例 = 色点 + 名称 + 百分比横条
- 柱状：圆角柱顶，双色对比（本期实色/上期浅色）
- 图表卡头部 = 标题 + 右侧 tabs

## 五、微习惯（高级感来源）

- 编号待办卡：1-4 彩色圆角数字 + 事项 + 右侧计数徽章
- 日历视图：事件 = 彩色小标签（类型即颜色），今天高亮
- 空状态/骨架屏/数字 count-up 动效全部要写到提示词里
- "Beta"、"专业版"（金色皇冠）、配额进度条——B 端产品的商业化组件

# 进阶：创作/自媒体工作台模式

来源：对 6 张"自媒体工作台"全功能截图的拆解（总览/研究/AI 报告/内容生产/素材库/发布复盘）。
在数据工作台底座上，创作工具多四类界面：**待办驱动、AI 流水线、素材管理、发布日历**。

## 八、创作工作台专属组件

### 8.1 问候式页头
```
你好！今天也是创作的好日子，继续加油！     ← 24px 粗标题 + 一句人话副标题
日期/天气右对齐
```
B 端工具的温度感来源：页头说人话，不说"欢迎使用"。

### 8.2 今日待办卡（首页 C 位）
- 卡片头：`今日待办 3/6`（完成数/总数，12px 灰）
- 复选列表：完成项 = 主色或绿色实心勾选框 + 文字加删除线弱化；未完成 = 空心框
- 每行右侧带 `2/3` 式的分子分母进度
- **这是首页的第一组件**——创作工具首页不是图表，是"今天该干什么"

### 8.3 迷你 KPI + 迷你趋势线
- 数字降为 20-24px（数据工作台是 28px），蓝色或墨色
- 每个 KPI 配一条 60×24 的 SVG sparkline（2px 线，无坐标轴，末端圆点）
- 趋势色约定：**金融/股票场景红涨绿跌；通用数据产品绿涨更常见**——全站只能选一种，不许混用

### 8.4 快捷入口卡（渐变回归）
创作工具允许品牌渐变回归（数据工作台禁止）：
- 4 张 2×2 或 1×4 卡：渐变底（蓝/紫/绿/橙各一）+ 白色线性图标 + 标题 + 一行说明
- 圆角 14-16px，hover 上移 2px

### 8.5 对标/研究列表
- 视频行：64px 缩略图（右下角压时长徽章 `02:34`）+ 标题 + 日期 + 三连数据（播放/点赞/评论）+ 标签 + 状态徽章 + 右侧操作
- 平台标签用**平台品牌色**：抖音（黑/红）、小红书（#FF2442 红）、B站（#FB7299 粉）、视频号（绿）
- 筛选行是标配：平台/标签/时间/排序下拉 + 关键词搜索 + 开关（仅看未拆解）+ 导出按钮

### 8.6 AI 报告文档页（拆解/分析结果）
创作工作台的杀手级界面——把 AI 输出排版成"可读的报告"：
- 报告头：返回链接 + 标题 + 副标题 + 右侧动作（重新拆描/保存报告/生成选题，主动作给 AI 渐变）
- 被分析对象卡片：缩略图 + 标题 + 平台标签 + 日期 + 数据
- 章节头 = 彩色软底图标 + 章节名（基础信息蓝/爆款结构红/表达画面紫）
- 编号步骤流：`01 开头3秒` `02 用户痛点` `03 解决方案`……每步标题 + 一句描述
- 双栏对照：`可借鉴方法`（绿 ✓ 列表）vs `风险点`（红 ! 列表）
- 差异化改编：编号卡片
- 下一步操作：3 张动作卡（生成口播稿/加入选题库/生成封面文案）

### 8.7 AI 操作按钮（贯穿全站的微模式）
- 所有 AI 能力触发点统一：** sparkle（四角星）图标 + 渐变或主色** + 动词开头（AI润色/AI润色/重新拆解/生成选题）
- 非 AI 动作用中性/描边样式，一眼可分"这是 AI 干的"

### 8.8 素材库
- 文件夹行：彩色文件夹图标 + 名称 + 素材数（32 个素材），颜色按类型轮换
- 工具栏：搜索 + 分类/标签/来源/时间四联下拉 + 网格/列表视图切换
- 文件行：类型图标（图文/视频/文档/音频，各有软底色）+ 名称 + 标签 + 时间
- 详情面板（右侧 380px 或下方卡）：预览 + 元信息（分类/标签/来源/创建时间/关联项目）+ 摘要 + 相关文件列表 + 操作（引用到项目/添加标签/归档/删除）

### 8.9 发布日历 + 复盘
- 周视图条：7 天日期列，今日高亮，事件用彩色小点 + 标题
- 待发布表：平台彩色方块图标（首字或 logo）+ 状态徽章（待发布蓝/已发布绿/待审核橙/待复盘灰）+ 优先级徽章（高红/中橙/低灰）
- 平台数据分布：横向条形 + 平台图标 + 百分比，品牌色
- AI 复盘卡：三段式——做得好的地方（绿 ✓）/ 可以改进的地方（橙 !）/ 下一步优化动作（蓝 →）+ 重新分析按钮

## 十、自检清单追加

- [ ] 待办卡是首页第一组件，不是图表
- [ ] 趋势色全站一种约定，无混用
- [ ] 平台标签/图标用平台品牌色
- [ ] AI 动作用 sparkle + 渐变，非 AI 动作用中性样式
- [ ] 报告页章节有彩色软底图标，编号步骤流清晰
- [ ] 缩略图带时长徽章；数据三连（播放/点赞/评论）格式统一（万/千分位）
