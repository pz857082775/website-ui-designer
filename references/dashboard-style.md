# 仪表盘 / 工作台 UI 提示词规范（B 端页面专用）

来源：对 6 张"AI 电商工作台"后台截图的拆解。工作台与营销页是两种生物：
营销页卖"感受"，工作台卖"效率"——**信息密度高、组件复用、状态语义化、数字可扫读**。

---

## 一、布局骨架（先定骨架再填内容）

```
┌──────────┬────────────────────────────────────────┐
│ Logo     │  搜索框(居中胶囊)            头像+姓名+角色 │
│ ───      ├────────────────────────────────────────┤
│ 分组导航   │  页面标题 22-24px 粗 + 灰色副标题            │
│ 图标+文字  │  ┌──┐┌──┐┌──┐┌──┐  KPI 卡行(4列)          │
│ 激活=蓝底  │  └──┘└──┘└──┘└──┘                          │
│          │  图表区(2/3 + 1/3 或 1/2 + 1/2)            │
│ ───      │  表格区(筛选行 + 表头 + 行 + 分页)            │
│ 升级卡片   │                                          │
└──────────┴────────────────────────────────────────┘
```

- 侧边栏 200-220px 固定，图标 + 文字导航，**激活项 = 主色 10% 软底 + 主色文字**；底部可固定运营卡片（升级/配额）
- 内容区间距 20-24px，卡片间距 16px
- 页面标题区固定三段式：大标题 + 一句话副标题 +（可选）右侧主按钮

## 二、KPI 卡解剖（工作台的第一组件）

```
┌────────────────────────┐
│ [彩色软底图标 38px]       │  ← 圆角 10-12px 软底(主色10-15%) + 同色线性图标
│ 可售库存        13px 灰  │
│ 12,560  28px 粗 tabular │  ← 数字永远 tabular-nums、千分位
│ ↑ 5.3%  较昨日 +630     │  ← 涨红跌绿(中国惯例)；"较昨日"12px 灰
└────────────────────────┘
```

**铁律**：
- 数字是绝对主角：26-30px、700 字重、等宽数字、千分位分隔
- 趋势色遵守中国股市惯例：**涨 ↑ 红、跌 ↓ 绿**（欧美工具反过来，别抄错）
- 图标 chip 颜色按语义分配（库存蓝/预警橙/销售绿/利润紫），同屏不重复用同一色
- 软底 = 色值 10-15% 透明度，不是纯色块

## 三、色彩系统（从截图提炼）

```
主色(蓝)   #3B7CF6 一族   导航激活/主按钮/链接/图表主线
AI 专属    紫渐变 #7C5CFC→#5B8EF4 + 机器人图标   ← AI 功能必须有独立视觉身份
语义色     成功 #34A853 / 警告 #F5A623 / 危险 #F04438 / 信息 #3B7CF6
中性阶     背景 #F5F7FA / 卡片 #FFFFFF / 分隔 #EEF0F4 / 主文字 #1F2329 / 次文字 #8A919F
```

- 语义色全部走"软底徽章"（bg 12% + 深色文字），**禁用大面积纯色块**
- AI 相关功能（助手、文案、策划、分析）统一紫色渐变 + 机器人/星星图标，是这套设计最聪明的记忆点

## 四、组件规范

**分段 Tabs**：`近7天 | 近30天 | 近90天 | 自定义`，激活 = 白底胶囊 + 轻阴影，或主色文字 + 底部 2px 指示条

**状态徽章**：软底圆角 6px，12px 字
`已完成`绿 / `待审核`橙 / `进行中`蓝 / `异常`红 / `无需补货`灰绿 / `建议补货`橙

**表格**：
- 行高 48-56px，浅色行分隔线（禁斑马纹）
- 筛选行 = 搜索框 + 下拉 + tabs + 右侧主按钮（"新建/导出"）
- 操作列 = 文字链接 + "更多"下拉
- 分页 = 总数 + 页码胶囊 + 每页条数下拉

**图表**：
- 折线：2-3px 圆角粗线 + 同色渐变面积填充，网格虚线 #EEF0F4
- 环形图：中心大数字 + 总计标签，图例 = 色点 + 名称 + 百分比横条
- 柱状：圆角柱顶，双色对比（本期实色/上期浅色）
- 图表卡头部 = 标题 + 右侧 tabs

## 五、微习惯（高级感来源）

- 编号待办卡：1-4 彩色圆角数字 + 事项 + 右侧计数徽章
- 日历视图：事件 = 彩色小标签（类型即颜色），今天高亮
- 空状态/骨架屏/数字 count-up 动效全部要写到提示词里
- "Beta"、"专业版"（金色皇冠）、配额进度条——B 端产品的商业化组件
