# 配色配方（Palette Recipes）

> 图 3 的问题不是"色值选错"，是**没有配色方法**：系统冷灰底 + 标准蓝 + 正红 + 三色标签。
> 本文件给 5 套可直接用的色板，以及 6 条"为什么好看"的判据。

---

## 一、6 条判据（配之前先过）

1. **底不用纯白，也不用系统冷灰**：用带 2–4° 色温的纸色（暖 `#F7F6F3` / 冷 `#F6F7F9`），卡片纯白形成 2–3% 明度差。
2. **主色必须是"深主色"**：明度 L\* 28–38%。L\* 55–60 的"标准蓝"（如 `#0B5FFF`）压白字只有 3.1–4.2:1，必然不达标——这是最常见的翻车点。
3. **语义色降饱和**：危险色混 8–12% 中性，用 `#A9502F` 而不是 `#FF0000`；成功用 `#2F6B57` 而不是 `#00C853`。
4. **一页最多 2 个有彩色系**（主 + 强调）。语义色不算色系，但四色同屏（红/绿/蓝/黄各一）＝廉价。
5. **中性阶带同一色相**：11 档，暖偏 30° 或冷偏 250°，步进在 oklch 里等距。
6. **深色不是反色**：底 `#0B–0E` 区间的带色黑，面提亮 6–8%，主色提亮到 L\* 60–70 后要重算白字对比；达不到就把主色压回深档。

## 二、五套色板（可直接抄，替换主色即可）

### A. 暖纸 + 松绿（医疗、健康、专业服务）
```
--bg #F7F6F3   --surface #FFFFFF   --surface-2 #F0EDE7
--ink #1C1B19  --ink-2 #46443F     --muted #6B6A66
--primary #1F4E46（白字 9.5:1）    --accent #B4552F（白字 4.9:1）
--success #2F6B57  --warn #8A5A2B  --danger #A9502F
深色：bg #0D0F10 / surface #171A1B / ink #ECEAE4 / primary #2E6F5E
```

### B. 冷灰 + 靛蓝（SaaS、数据、工具）
```
--bg #F6F7F9   --surface #FFFFFF   --surface-2 #EEF1F5
--ink #14171C  --ink-2 #414750     --muted #5E6673
--primary #2B4C7E（白字 8.6:1）    --accent #B45309（琥珀，白字 5.1:1）
--success #1F6B4E  --warn #8A5A00  --danger #A33B2A
```

### C. 米墨（品牌、编辑、文化）
```
--bg #F4F1EA   --surface #FFFFFF   --surface-2 #EBE6DB
--ink #171614  --ink-2 #45423C     --muted #6A665E
--primary #2A2A28（近黑，白字 13:1）--accent #A8582A（赭石，白字 4.8:1）
```

### D. 石墨 + 苔绿（开发者、监控、深色产品）
```
--bg #0E1114   --surface #161A1E   --surface-2 #1D2227
--ink #E9EAE6  --ink-2 #BFC3BE     --muted #98A09A
--primary #4EA88A（深字 #08120E，对比 7.8:1）--accent #D08A4E
--line rgba(233,234,230,.12)       /* 深色用亮描边表达层级，不用阴影 */
```

### E. 明亮生鲜（电商、食品、消费）
```
--bg #F7F7F4   --surface #FFFFFF   --surface-2 #EFF2EE
--ink #1A1D1A  --ink-2 #3E463F     --muted #5C665F
--primary #1F6B4A（白字 7.4:1）    --accent #C2410C（价格/促销，白字 5.4:1）
```

## 三、选型表（按行业，不按喜好）

| 行业 / 场景 | 推荐 | 为什么 | 别用 |
|---|---|---|---|
| 医疗 / 健康 | A | 暖纸降低"医院冷感"，松绿表达稳定 | 系统蓝 + 正红（像 HIS 系统） |
| SaaS / 数据 | B | 冷灰撑密度，靛蓝显专业 | 紫蓝渐变（AI 味） |
| 品牌 / 编辑 | C | 米墨靠排版取胜，不靠颜色 | 高饱和多色 |
| 开发者 / 监控 | D | 深色省电、亮描边分层 | 纯黑 + 霓虹绿 |
| 电商 / 食品 | E | 暖白显新鲜，橙红只给价格 | 红配绿（廉价） |

## 四、反例解剖（图 3 为什么"丑"）

**原始配色**：底 `#F2F2F7`（系统冷灰）+ 主色 `#0B5FFF`（标准蓝）+ 环 `#C0392B`（正红）+ 标签 蓝/琥珀/绿 三色同屏。

| 问题 | 为什么难听 | 改法 |
|---|---|---|
| 冷灰底 + 纯白卡 | 明度差 3%，但色温割裂，像网页版 HIS | 换暖纸 `#F7F6F3`，白卡自然浮起 |
| 标准蓝 `#0B5FFF` | 压白字 3.16:1（不可读），且是"默认色" | 换深松绿 `#1F4E46`（9.5:1） |
| 正红 `#C0392B` | 纯红与蓝冲突，医疗场景更显警示过度 | 换赭红 `#A9502F`（降饱和） |
| 三色标签 | 蓝/琥珀/绿同屏 = 没有主色 | 统一为"主色淡底 + 深字"，仅风险标签用赭 |
| 环与文字同权重 | 62 的数字与环颜色互相抢 | 环用赭、数字用 ink（文字不染色） |

## 五、落地检查（3 条）

```
[ ] 主色 L* 是否在 28–38%（白字能到 ≥7:1）
[ ] 底是否是带色温的纸色（不是 #FFFFFF / #F2F2F7 / #F5F5F5）
[ ] 同屏有彩色系 ≤2（不含语义色），语义色面积 ≤5%
```
