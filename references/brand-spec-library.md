# 品牌规范库与行业规则（Brand Spec Sources）

> 核实（2026-10-25）：
> `nextlevelbuilder/ui-ux-pro-max-skill` 140k★ MIT（v2 内置 **192 套配色** + Design System Generator）｜
> `nexu-io/open-design` 104k★ Apache-2.0（**151 个设计系统包**，以 `DESIGN.md` 为品牌契约）｜
> `getdesign` npm 0.6.26（把 `DESIGN.md` 模板装进项目）
>
> 用途：**快速拿到一个"有依据的起点"**，而不是从零猜配色与字体。

---

## 一、三个来源，各取什么

| 来源 | 怎么用 | 给你什么 | 别指望 |
|---|---|---|---|
| **ui-ux-pro-max** | 装成 AI 技能（`npm i -g uipro-cli` → `uipro init --ai claude`） | 行业 → 风格/配色/字体搭配/推理规则；v2 的 Design System Generator 能直接出整套令牌 | 它给的是"统计意义上的合适"，不是你的品牌差异 |
| **open-design** | 本地跑工作台，或直接读仓库里的 `design-systems/<brand>/` | 151 个品牌包：`DESIGN.md` + `tokens.css` + 组件 + 资产说明 | 品牌包是**参考**，logo/字体/图形不能直接商用复制 |
| **getdesign** | `npx getdesign@latest add vercel` | 把某个品牌的 `DESIGN.md` 装进项目，LLM 可直接读 | 它是"规范文档"，不含组件实现 |

## 二、从品牌规范里只提取四件事

拿到任何一份品牌规范（Stripe / Linear / Vercel / Apple / Notion），**不要照抄视觉**，只取这四项：

```
① 色阶结构：主色几档？中性几档？语义色怎么分配？强调色一屏出现几次？
② 字阶关系：几档字号？比例多少？字重几个？标题用衬线还是无衬线？
③ 组件契约：按钮几种变体？圆角分级？边框还是阴影表达层级？
④ 布局栅格：内容最大宽？分栏比例？区块间距节奏？
```

再补一项**品牌禁忌**：这个品牌刻意不做什么（例如 Vercel 几乎不用色彩、Stripe 用图表承载密度）。
**禁忌比规则更能防止跑偏。**

## 三、映射到我们的 12 个令牌

```markdown
| 我们的令牌 | 从品牌规范取什么 | 例：某品牌 |
|---|---|---|
| --color-bg | 最浅中性 | #F7F7F5 |
| --color-surface | 卡片白（或略暖） | #FFFFFF |
| --color-ink | 正文深色（不用纯黑） | #111111 |
| --color-ink-muted | 次要文字（仍需 4.5:1） | #666666 |
| --color-border | 描边（半透明优先） | rgba(0,0,0,.08) |
| --color-accent | 主色（一屏 ≤5 处） | #0A66C2 |
| --color-success/warning/danger | 语义色 | … |
| --radius-* | 圆角分级 | 6 / 12 / 18 |
| --font-* | 字族与字阶 | Sans + Mono |
| --shadow-* | 两级阴影 | … |
```

**映射完必须跑**：
```bash
python scripts/audit_contrast.py page.html --pairs="--ink:--bg,--ink-muted:--bg,--accent-ink:--accent"
```
品牌规范里的"次要文字"经常不达标（见 A-002），照抄会踩坑。

## 四、行业规则速查（启发式，不是定论）

> 这些是"默认值"，用来在用户没说清时给一个合理起点；有品牌规范时以品牌为准。

| 行业 | 配色倾向 | 字体倾向 | 密度 | 常见禁忌 |
|---|---|---|---|---|
| 金融 / 支付 | 深蓝、墨绿、中性灰 | 无衬线 + 等宽数字 | 中高 | 紫粉渐变、卡通插画、圆角过大 |
| 医疗 / 健康 | 蓝绿、白、低饱和 | 无衬线、字号偏大 | 中 | 高饱和红、深色主界面（焦虑） |
| 法律 / 政务 | 深蓝、酒红、灰 | 衬线标题 + 无衬线正文 | 中 | 花哨动效、网络流行语 |
| 工业 / 制造 | 石墨、安全黄/橙、单强调 | 粗字重、等宽数字 | 高 | 玻璃拟态、低对比灰字（车间强光） |
| 教育 / 亲子 | 明亮但低饱和、圆角大 | 圆体/高 x-height | 低中 | 小字号、密集表格 |
| 奢侈品 / 酒店 | 米白、墨、金（少量） | 衬线 display | 低 | 高饱和渐变、促销红 |
| 开发者工具 | 近黑/白、单强调（绿/蓝） | 无衬线 + 等宽 | 中高 | 装饰插画、营销式大标题 |
| 电商 / 零售 | 白底 + 品牌色 + 促销红 | 无衬线，价格等宽 | 中高 | 过多强调色（价格失去焦点） |

**用法**：先按行业取默认 → 再用"五轴组合"（3.13）至少改 2 个轴，避免所有同行一个样。

## 五、合规红线（必须遵守）

1. **不复制 logo、品牌图形、专有插画**——规范是参考结构，不是素材库
2. **字体必须单独授权**：品牌用的商业字体不能因为"规范里写了"就商用
3. **不宣称关联**：不要写"Vercel 风格官方推荐"这类暗示
4. **保留来源**：交付里注明"参考了 X 的公开设计规范的结构"，避免抄袭争议
5. **色彩可借鉴、不可照搬**：同一组色值 + 同一套版式 = 山寨；换色相/换骨架/换字体才算自己的

## 六、落地流程（半天可完成）

```
1 取规范：npx getdesign@latest add <brand>（或读 open-design 的 design-systems/<brand>）
2 提取四件事 + 品牌禁忌，写进项目的 DESIGN.md
3 映射到 12 个语义令牌（浅/深各一套）
4 跑 audit_contrast.py，0 违规
5 用五轴组合改 ≥2 个轴，形成自己的差异
6 记住点（3.11）只留 1 个
```
