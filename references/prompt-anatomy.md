# 提示词解剖 — 参考图的 5 行式写法（本技能的风格段标准句式）

来源：对 4 张获奖参考图原始 prompt 的精确提取。所有风格提示词**必须**按此解剖书写——短句、祈使句、每行只干一件事。

## 五行的职责（固定顺序）

| 行 | 职责 | 句式 |
|---|---|---|
| 第 1 行 | 定性 | `把页面改成{风格名}风格` |
| 第 2 行 | 配色 | `{背景色}背景 搭配{主色/辅色} 文字用{色}` |
| 第 3 行 | 布局 | `{留白/对齐/圆角/字号跨度} 方面的具体动作` |
| 第 4 行 | 强调 | `只用一种强调色 / {强调色}只用于{主按钮和关键链接}` |
| 第 5 行 | 感受 | `让页面{目标感受} 重点依然{清楚/突出}` |

**反面教材**（AI 默认脸）：把五行揉成一段形容词堆砌（"现代感、高级感、科技感十足……"）——模型无法执行形容词，只能执行动作。

## 参考图原始 Prompt 存档（原文照录，作为措辞基准）

### 01 / MODERN MINIMALISM 极简留白
> 简单一点 好看得刚刚好
```
把页面改成极简留白风格 暖白背景 深灰文字
只用一种强调色 拉开标题大小 统一对齐 增加留白
突出核心内容和主要按钮
让页面干净又有重点
```

### 02 / SOFT MUTED 莫兰迪柔和
> 第一眼舒服 越看越喜欢
```
把页面改成柔和低饱和风格
暖白背景 搭配鼠尾草绿 灰粉或浅沙色
留白舒展 圆角柔和 减少生硬的边框与阴影
正文用深灰 主要按钮用更深的品牌色
让页面温柔耐看 重点依然清楚
```

### 05 / MINIMAL 3D SPACE 极简 3D 空间
> 让产品像件展品 值得认真看一眼
```
使用极简3D空间风格
在干净背景中放置一个精致的立体主视觉
通过柔和光影 透视和前后遮挡表现空间
搭配简洁大标题与充足留白
主要按钮清晰醒目
```

### 08 / GLASSMORPHISM 玻璃美学
> 轻一点 透一点 界面也有呼吸感
```
把页面改成通透玻璃风格
让半透明面板悬浮在简洁背景上
搭配适度背景模糊 微亮边缘和轻柔阴影
玻璃效果集中在导航与控件
正文对比清晰 主要按钮容易识别
```

## 从参考图学到的三条铁律

1. **先定性再展开**：第一行必须是"把页面改成 X 风格"这种不可含糊的指令，模型对风格名的先验知识远比对形容词堆砌的可靠
2. **约束用数字和动作，不用形容词**："增加留白"→"区块留白 ≥ 120px"；"拉开标题大小"→"标题 88px / 正文 17px，跨度 ≥3 倍"
3. **最后一行永远落在感受 + 重点**：`让页面{感受}，重点依然{突出}`——这是防止模型为风格牺牲信息层级的保险丝

## 扩展示例（按同解剖写的新风格）

### 暗色杂志 Dark Editorial
```
把页面改成暗色编辑排版风格
近黑背景 纯白正文 一种高饱和强调色
超大压缩体标题 网格细线分栏 杂志式不对称排版
图片灰度处理  hover 恢复彩色
强调色只用于一个 CTA
让页面克制但有张力 标题就是视觉主体
```

### 柔和新粗野 Soft Neo-Brutalism
```
把页面改成柔和新粗野风格
奶油底色 高饱和主色块 粗实线描边配硬阴影
大圆角与硬阴影中和攻击感 保持友好
色块承载交互 按钮和标签即层级
微交互活泼 按下阴影收回
让页面有个性但不刺眼 信息依然一眼可读
```
