# 风格库 — 专业提示词模板（填空即用）

每条提示词按"参考图案例"的写法提炼：先定性，再给可执行的视觉指令。`{占位符}` 填入需求细节。
**所有条目遵循 `prompt-anatomy.md` 的 5 行式解剖（定性→配色→布局→强调→感受）；原文存档与措辞基准见该文件。**

## 01 / MODERN MINIMALISM 极简留白
> 简单一点，好看得刚刚好。适用：SaaS、作品集、咨询、开发者工具。

```
把页面改成极简留白风格：
- 暖白背景（{#FAFAF8}），深灰文字（{#1A1A1A}），只用一种强调色（{品牌色}）
- 拉开标题大小：H1 用 64-96px/负字重字距，正文 16-18px，字号跨度至少 3 倍
- 统一 8pt 网格对齐，区块留白 ≥ 120px，留白就是设计
- 强调色只用于主按钮和关键链接，全页唯一高强调元素是主 CTA
- 突出核心内容：首屏一句话价值主张 + 一个主按钮，其余全部退后
- 让页面干净又有重点：删除一切不承载信息的装饰
```

## 02 / SOFT MUTED 莫兰迪柔和
> 第一眼舒服，越看越喜欢。适用：生活方式、教育、活动、品牌站。

```
把页面改成柔和低饱和风格：
- 暖白背景（{#F5F3EE}），搭配鼠尾草绿 {#A8B5A0} / 灰粉 {#D9C5C0} / 浅沙色 {#E4D8C8}
- 大标题可用超大背景字（低饱和主色、10-20% 透明度）压在区块后面制造层次
- 留白舒展，圆角柔和（16-24px），减少生硬边框，用阴影层级代替描边
- 正文用深灰 {#3D3D3D}，主按钮用更深的品牌色（保证对比度 ≥ 4.5:1）
- 图片区加柔和遮罩渐变融入背景，卡片信息分层：标题/描述/标签三级灰度
- 让页面温柔耐看，重点依然清楚
```

## 03 / GLASSMORPHISM 玻璃美学
> 轻一点，透一点，界面也有呼吸感。适用：科技产品、AI 工具、数据面板。

```
把页面改成通透玻璃风格：
- 半透明面板（rgba 白 8-15% + backdrop-filter: blur(20px)）悬浮在简洁背景上
- 背景放 1-2 个大尺寸柔和色斑（品牌色系、blur 80px 以上），不要花哨渐变
- 玻璃效果集中在导航栏与核心控件，卡片有微亮边缘（1px 内描边 rgba 白 20%）
- 轻柔阴影（0 8px 32px rgba 黑 8-12%），保持悬浮感但不厚重
- 正文对比清晰（深色文字或纯白文字按背景切换），主要按钮用实色容易识别
- 3D 展示物/主视觉放在玻璃面板之间，形成前后景深
```

## 04 / MINIMAL 3D SPACE 极简 3D 空间
> 让产品像件展品，值得认真看一眼。适用：硬件、金融、高溢价品牌、发布页。

```
使用极简 3D 空间风格：
- 干净背景（纯白或近黑）中放置一个精致的立体主视觉（产品渲染/3D 形体/毛毡质感模型）
- 通过柔和光影、透视和前后遮挡表现空间感，主视觉允许跨区块边界制造张力
- 搭配简洁大标题（全大写粗体可选）与充足留白，文案极短
- 主要按钮清晰醒目（高对比实色或反色块）
- 点缀一个高亮强调色（如荧光绿/橙）只用于一处标签或 CTA
```

## 05 / DARK EDITORIAL 暗色杂志风
> 克制的黑，放大的字。适用：创意机构、音乐、潮流、开发者品牌。

```
把页面改成暗色编辑排版风格：
- 近黑背景（{#0A0A0A}），纯白正文，一种荧光/高饱和强调色
- 超大衬线或压缩体标题（clamp 48-140px），标题就是视觉主体
- 网格线/细分割线（rgba 白 10%）划分区块，杂志式不对称排版
- 图片用灰度处理，hover 恢复彩色；分隔符用编号（01/ 02/）制造秩序感
- 动效克制：标题逐行揭示、图片视差，不抢内容
```

## 06 / SOFT NEO-BRUTALISM 柔和新粗野
> 有个性的清爽，不是乱。适用：创意工具、年轻品牌、活动页。

```
使用柔和新粗野风格：
- 奶油/浅色底 + 高饱和主色块，卡片用粗实线描边（2-3px）+ 硬阴影（offset 4-6px 无模糊）
- 大圆角（20-32px）和硬阴影中和攻击性，保持友好
- 字重对比拉满：800-900 标题 + 400 正文
- 强调色块承载交互（按钮、标签、高亮卡片），色块即层级
- 微交互活泼：按钮按下阴影收回、卡片 hover 平移 2px
```
