# 模式 C：已开发界面 → 审计 + 定向美化提示词（完整流程）

> **状态（v2.3.0）：已冻结。** 与 `diagnosis-protocol.md` 重叠且没有优先级算法。审现有页面一律走 **diagnosis-protocol 的七项扫描**。

适用：页面已经存在（线上或本地），用户觉得"不好看但说不上哪不对"。
原则：**不重写整页，最小改动，定向修复。**

## C1 走查（收集不舒服点）

对页面在 375 / 768 / 1440 三档宽度截图，逐屏记录"不舒服点"，只记现象不记方案：
- "这里有点挤" / "这块颜色很跳" / "字看不清哪个是重点" / "动画很碎"

## C2 归类（五类病）

| 类 | 症状 | 典型根因 |
|---|---|---|
| 配色土 | 颜色刺眼/发灰/脏 | 饱和度高、无中性阶、强调色滥用 |
| 间距乱 | 拥挤或空洞、不对齐 | 无间距体系、magic number、没走 8pt 网格 |
| 层级弱 | 不知道先看哪 | 字号无跨度、字重无对比、强调色到处都是 |
| 动效杂 | 动画碎、卡、碍事 | 时长随机、动布局属性、无缓动意图、数量超载 |
| 组件糙 | 按钮/卡片/输入框不精致 | 圆角阴影不统一、状态缺失（hover/focus/disabled） |

## C3 写定向修复提示词（每类一段，句式库）

**配色类**
```
把页面的配色整理成一套克制的色板：
背景用 {色}，卡片面用 {色}，正文主色 {色}、次色 {色}；
强调色只保留 {色} 一种，只用于主按钮和关键链接；
把饱和度超过 {值} 的颜色降下来，全页色相家族不超过 2 个。
```

**间距类**
```
把全页间距统一到 8pt 网格：
区块垂直留白统一为 {96|128|160}px，卡片内边距 {24|32}px；
组件间距只用 8 的倍数（8/16/24/32/48）；
删掉所有 1px 分隔线，用留白分区。
```

**层级类**
```
重建视觉层级：标题 {88}px / 小标题 {40}px / 正文 {17}px，字号跨度拉开到 3 倍以上；
每个区块只允许一个最醒目的元素；
主按钮是全页唯一的高强调组件，其余按钮全部降级为描边或文字按钮。
```

**动效类**
```
把页面上所有动画收敛为一套动效语言：
入场统一为 {元素} 从下方 {40}px 淡入上移，duration 0.6s，power3.out，stagger 0.08s；
只允许 transform 和 opacity 参与动画；
加上 prefers-reduced-motion 降级（动画跳过，内容直接可见）；
删除一切循环漂浮、闪烁、无信息量的装饰动画。
```

**组件类**
```
把全页按钮和卡片整理成两个组件：
按钮分三级：主按钮（实色）/ 次按钮（描边）/ 文字按钮；圆角统一 {8}px，hover/active/focus/disabled 四态齐全；
卡片统一圆角 {16}px、边框 1px {色}、阴影一级 {值}，hover 时上移 4px；
删掉渐变、发光、彩色图标方块。
```

## C4 生成与对比验收
- 每段提示词单独执行、单独验收（改配色不动布局）
- 同位置截图对比，确认"只好了该好的地方"
- 每轮最多执行 2 段（避免一次改太猛回不去），最多 3 轮

## C5 收尾
全部修复完成后，把最终状态回写成一份 DESIGN.md（本次会话确认的令牌），沉淀给后续迭代。
