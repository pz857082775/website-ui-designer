# 品牌方向与"昂贵感"（Brand Direction）

> 整合自 `mouse-lin/finesse-skill`（skills/finesse-ui，MIT）。
> 解决的问题：**同一个方法，必须能产出视觉上互不相关的页面**，而不是十张同一张脸。

---

## 一、三个旋钮（写方案前先声明）

| 旋钮 | 1-3 | 4-6 | 7-10 |
|---|---|---|---|
| **SOUL** 人格强度 | 中性、安全、系统默认 | 有明确气质 | 独一无二、一眼可辨 |
| **SPECTACLE** 技术野心 | 静态 + CSS | 滚动动画、Canvas 点缀 | WebGL/GLSL hero、滚动影院 |
| **DENSITY** 信息密度 | 一屏一个观点 | 平衡 | 编辑式、数据密集 |

### 1.1 旋钮推断（按行业，不按喜好）

| 行业 / 类型 | SOUL | SPECTACLE | DENSITY |
|---|---|---|---|
| 天文 / 音乐 / 游戏 / 加密 / 潮流科技 | 7-9 | **7-10** | 3-5 |
| 法律 / 金融 / 医疗 / B2B SaaS 营销 | 5-7 | **3-5** | 4-6 |
| 传承 / 奢侈 / 编辑 / 出版 | **8-10** | 4-6 | 3-5 |
| **任何产品界面**（后台/仪表盘/App） | 5-7 | **1-4** | **6-9** |
| H5（移动） | 5-8 | 按"形态"花预算，不是按行业 | 3-5 |

**产品界面的特权**：不需要 hero engine，把预算花在数据可视化与组件系统上。

### 1.2 "宣称即交付"（硬闸门）

`SPECTACLE ≥ 7` → 页面**必须真的**有一个能跑、能降级、中端机 60fps 的视觉引擎。
只做了渐变光斑却宣称 8 = 交付破损。做不到就把旋钮降到 4，做一个工艺精良的静态页。
**永远不要半成品引擎**——卡顿或中途截断，比没有更廉价。

## 二、反同质化：五轴组合，而不是选模板

> 从十个人设里挑一个，模型永远落在那两三个它见得最多的。

**五个正交轴**，各取一个值，组合即人格：

```
A 配色结构：单色+一个酸性色 / 双色互补 / 中性+暖强调 / 低饱和多色阶 / 黑白+单点
B 字体关系：衬线标题+无衬线正文 / 单一无衬线+极限字重差 / 等宽主导 / 展示体+小字正文
C 版式家族：非对称栅格 / 编辑式分栏 / 满幅图+浮层 / 拼贴 / 单列长文
D 动效引擎：CSS-only / GSAP 滚动 / Canvas 2D / WebGL / 无（静态）
E 材质隐喻：纸感颗粒 / 金属拉丝 / 玻璃 / 印刷网点 / 纯数字平面
```

**反重复机制（必须可执行）**
- 维护"最近 5 次构建的坐标表"（写进项目 `.design/log.md`）
- 新方案必须与上一条在 **≥3 个轴上不同**
- 设"饱和赛道"黑名单：编辑式排版、米色+黄铜、AI 紫光——作为**默认**禁用，要有理由才用
- 两个方向打平时**掷骰子决定**，并写下为什么（防止模型偷懒选最眼熟的那个）

## 三、"昂贵感"的物理层（为什么有的页面显贵）

> 廉价与高级的差别，往往是一层很薄的物理感，且始终一致。

**通用工艺底线（产品界面也适用）**
- **半透明描边**：深色 `rgba(255,255,255,.07-.22)`，浅色 `rgba(0,0,0,.06-.08)`；不用硬 `#333` 线
- **不用纯白/纯黑**：每个中性色都朝品牌色相偏 2-6 点
- **色彩锁定**：选了强调色，它拥有整页；不允许"玫瑰色页面里突然冒出青色徽章"

**品牌页专属（后台不要用）**
- **颗粒**：固定 SVG `feTurbulence` 噪点，`opacity .025-.05`（浅色更低）——消除"矢量塑料感"
- **暗角**：深色 hero 上加径向渐变压暗，制造光学焦点
- **字体张力**：`clamp()` 大标题 + 负字距 `-0.02 ~ -0.045em` + 行高 `.86-.95` + 极限字重对比（900 对 300）
  - **例外（高频翻车）**：全大写标题行高下限 **1.0**，推荐 1.02-1.08。全大写没有下伸部，`.86` 会让第二行大写字母撞上第一行的基线，手机上必然糊成一条墨带
- **分层 z-index**：引擎(0) · 颗粒(1) · 暗角 · 内容(5)

**用 OKLCH 思考配色**：感知一致、易做浅深配对；输出可以是 hex，但决策在 OKLCH 里做。

## 四、Hero 引擎（品牌页只允许一个）

| 引擎 | 什么时候用 | 成本 |
|---|---|---|
| Three.js + GLSL | 3D 纵深、粒子系统、metaball、bloom | 重；懒加载，SPECTACLE ≥7 才用 |
| Canvas 2D | 粒子、场、实时数据（K 线、波形） | 轻；适配 DPR |
| WebGL FBO | 流体、反应扩散、光线步进、虹彩 | 重；一次全屏 quad，多 pass |
| GSAP ScrollTrigger | 滚动叙事、横向平移、视差、交错揭示 | 中；最可复用 |
| CSS-only | 双层遮罩、3D 变换、可变字体、滚动驱动动画 | 免费；性能最好 |

**纪律**
- **一页只有一个**技术高光，做满 100%
- **渐进增强**：去掉引擎，页面仍完整可读；引擎不做内容承重
- **60fps 或简化**：只动 `transform/opacity`；中端机测，不是你的机器
- `prefers-reduced-motion`：冻结成静帧或换成编排好的静态 hero
- **动机明确**：每个滚动/跑马灯/钉住段落都要一句话理由；跑马灯一页最多 1 个

**组件级 3D ≠ hero 引擎**：指针倾斜卡、翻转卡、coverflow、景深视差属于"可复用的页内 3D"，默认用 CSS 层，零成本。
**一页只有一个 3D 时刻**：不要 hero 引擎 + 倾斜网格 + coverflow 三件套齐上。

## 五、四种页面骨架（单一序列本身是同质化的根源）

> 如果每个品牌页都是 `HERO → 跑马灯 → 宣言 → 网格 → CTA → 页脚`，那它们就是同一页。

| 类型 | 结构 | 承重段 |
|---|---|---|
| **落地/发布**（"有个东西，要被理解"） | HERO（引擎时刻）→ 规格条（4 列细线 + 真数字）→ **论证**（爆炸图/演示/整页引擎，展示它真的在工作）→ 非对称产品栅格（1.4fr 1fr）→ 技术纵深（深色反转）→ 超大 CTA → 页脚 | **论证**：只"声称"好的落地页是宣传册 |
| **作品集**（"作品是论据，你不是"） | 全幅图或一句陈述 → 作品（胶片手风琴/生成网格/列表行+缩略图）→ 宣言（一段单列）→ 能力（列表不是卡片）→ 单个项目深挖 → 超大字号联系 → 页脚 | **作品**：作品前放"关于我"就是简历 |
| **Lookbook**（"勾引"） | 满幅图流 → 节奏变化（大图/双联/细节）→ 材质特写 → 购买/预约入口 | **节奏**：不能每屏一样大 |
| **工作室**（"证明能力"） | 一句定位 → 精选案例（少而深）→ 方法（编号有意义才编号）→ 团队 → 联系 | **案例深度** |

**编号（01/02/03）只在内容真的是序列时使用**：步骤、时间线、榜单。并列卖点用编号 = AI 味。

## 六、廉价黑名单（补充到主文件 12 条红线）

来自 finesse-ui 的合并清单，**新增这些**：

| 红线 | 为什么 |
|---|---|
| 正文里用长破折号（—）做修饰 | 最常被识别的"AI 写作指纹" |
| 渐变文字 | 与内容无关的装饰，且对比度不可控 |
| 默认玻璃拟态 | 2021 年后的模板味；除非品牌确实以玻璃为材质 |
| 每节都挂 eyebrow（全大写小标签） | 模板语法，不是信息结构 |
| 把 01 · 02 · 03 当默认架构 | 只有真序列才配编号 |
| 完全相同的卡片栅格（图标+标题+文案 ×6） | 组内无差异 = 没有信息层级 |
| div 拼的假截图 / 假仪表盘 | 一眼假，且违背"展示真实" |
| 假精确数字（92%、4.1×）无来源 | 信任成本最高的一类 |
| 类别默认配色（工艺=米色+黄铜，AI=紫光） | 命名它，然后拒绝它 |
| Inter / Fraunces 等无理由默认 | 有理由可以，盲选即指纹 |
| 该有图的位置没有图（hero/画廊/商品图/空状态） | 这是 bug，不是极简；反过来"用户没同意就塞图"同样错 |

## 七、移动端六条硬规则（finesse-ui 的 mobile floor）

在 **320 / 375 / 414 / 768** 四个宽度测，不要拖窗口直到"看起来还行"。

```
M1 html 与 body 都用 overflow-x: clip（不是 hidden——hidden 会造出滚动容器，静默杀死 sticky 后代）
M2 含图的网格轨道写 minmax(0,1fr)（裸 1fr 的 auto 最小值是图片固有宽度）；flex 子项加 min-width:0
M3 可点击文字在任何宽度都不换行：先缩短文案，再考虑 nowrap
M4 展示级标题加 overflow-wrap:anywhere; min-width:0
M5 只允许一个 top:0 的 sticky；其余用 --nav-h 偏移，并让 --z-nav 高于 --z-sticky
M6 全大写标题行高下限 1.0（见第三节）
```

`M1/M2/M5/M6` 可以脚本化检测；`M3/M4` 必须在 320px 渲染后才看得出来。
