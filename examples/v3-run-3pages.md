# 一、AI 产品官网首页（PC Web）

## 1 需求解析

- 用户：SaaS 平台负责人 / 研发主管，30–45 岁，桌面，决策期停留 40–90 秒

- 关键页面：首页（5 屏滚动）

## 2 定调
```
参考 1：Stripe —— 借鉴「表格作为证据、细线分区」的手法
参考 2：Linear —— 借鉴「1px 低对比描边 + 单一强调色 + 高密度」的手法
情绪词：精确 → 8pt 网格 / 数字等宽 / 圆角 ≤12
        安静 → 暖纸底 #F7F7F4 / 无渐变 / 全站 1px 描边
        有据 → 每个数字标口径（n=1,240）
```

## 3 Design Spec
| 项 | 值 |
