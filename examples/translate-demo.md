# 三句话 → 术语 → 模板 → 规范：一次完整翻译

> 证明三块能力能串起来：**听懂（术语库）→ 有参照（模板库）→ 能落地（规范工具）**。
> 每条都可复现：`python scripts/term_lookup.py "<原话>"`

---

## 例 1：「底部按钮被那条黑杠挡住了，点不到」

**① 查术语**
```bash
$ python scripts/term_lookup.py "按钮被底下那条黑杠挡住了"
1. 【安全区 safe area】H. 响应式与多端
   定义：刘海与 Home 条避让
   参数：env(safe-area-inset-*)
   命中：症状:挡住
2. 【固定层 fixed】A. 布局与结构
   参数：必须给内容预留高度 + 安全区
```

**② 说人话**
> 这不是"按钮位置不对"，是**安全区**没留。吸底栏没有把 iPhone 底部的 Home 条区域算进去。

**③ 落参数**
```css
.bar{padding-bottom:calc(12px + env(safe-area-inset-bottom))}
body{padding-bottom:calc(88px + env(safe-area-inset-bottom))} /* 内容不被吸底遮住 */
```
**④ 选模板**：移动端详情 / 列表（模板 17 / 18），两者都要求"吸底 + 安全区"。
**⑤ 验收**：滚动到底，最后一行可完整读到；固定层不覆盖任何可点元素（§5.6）。

## 例 2：「页面看着有点土，说不上来」

**① 查术语**
```bash
$ python scripts/term_lookup.py "页面太土了"
1. 【中性阶 neutral ramp】D. 色彩   参数：11 档，带同一色相（暖 30°/冷 250°）
2. 【饱和度 saturation】D. 色彩     参数：主色 ≥60%；语义色 ≤70%
```

**② 说人话**
> "土"通常不是配色不好看，是**中性阶是死灰（#F5F5F5）+ 饱和度不敢提**。
> 灰没有色温、主色又偏灰，整页就显得脏。

**③ 落参数**（来自 `library/palette-recipes.md` A 套）
```css
--bg:#F7F6F3;      /* 暖纸，替掉 #F5F5F5 */
--ink:#1C1B19;     /* 带暖调的黑 */
--primary:#1F4E46; /* 深主色，白字 9.5:1 */
--accent:#B4552F;  /* 语义色降饱和 */
```
**④ 选模板**：品牌首页 / 落地页（模板 1 / 2）——先用结构撑住，再谈颜色。
**⑤ 验收**：主色面积 ≤10%、有彩色系 ≤2、正文对比 ≥4.5:1。

## 例 3：「信息太多了，看着累」

**① 查术语**
```bash
$ python scripts/term_lookup.py "太挤了"
1. 【间距系统 spacing scale】B. 间距与几何  参数：4/8 基准 …
2. 【字距 tracking】C. 排版                参数：正文 0
```

**② 说人话**
> "累"通常是三件事叠加：**间距不统一**（13/27 这种值）、**行高偏紧**、**没有分层**（所有信息同一字号）。

**③ 落参数**
```css
/* 间距只用 9 档 */
--s4:16px; --s6:24px; --s8:32px; --s12:48px;
/* 行高分场景 */
body{line-height:1.65}          /* 正文 */
h2{line-height:1.2}             /* 标题 */
/* 三级降权：不是删信息 */
.t1{font-size:28px;font-weight:700}
.t2{font-size:16px;font-weight:500}
.t3{font-size:13px;color:var(--muted)} /* 仍 ≥4.5:1 */
```
**④ 选模板**：数据工作台 / 列表（模板 9 / 10）——它们内置"折叠 + 降权"的处理位置。
**⑤ 验收**：单屏信息组 ≤5、每组 ≤7 项、空域 ≥35%（营销）/ ≥25%（后台）。

## 三块能力的分工

| 能力 | 回答什么 | 产物 | 失败的样子 |
|---|---|---|---|
| 术语库（110 条） | 用户到底在说什么 | 术语 + 参数 | 直接改样式，猜错方向 |
| 模板库（21 类） | 该长成什么结构 | 骨架 + 状态清单 | 从零画，漏状态 |
| 规范工具 | 怎么写成代码 | 令牌 + 六区块 + 五件套 | 只有文字方案，无法实现 |

**串起来就是一条线**：
```
原话 → term_lookup（术语）→ ui-templates（结构）→ design-spec-kit（令牌+骨架）→ audit_all（验收）
```
