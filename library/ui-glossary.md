# UI 术语库（Glossary）

> 用途：把用户的大白话翻译成可执行的界面语言。
> 每行四列：**术语** ｜ **用户可能怎么说** ｜ **一句话定义** ｜ **落地参数/判定**。
> 查法：`python scripts/term_lookup.py "太挤了"`（按用户原话反查）。

---

## A. 布局与结构

| 术语 | 用户可能怎么说 | 定义 | 落地参数 |
|---|---|---|---|
| 栅格 grid | "排版乱""对不齐" | 把页面切成等宽列，元素跨列对齐 | 12 列 / 沟槽 32 / 页边距 64（桌面） |
| 最大内容宽 max-width | "太宽了看不完" | 内容区上限，超出后居中留白 | 产品 1200，营销 1440 |
| 分栏 column split | "左右分开""一边图一边字" | 一屏切成两个主区 | 7:5 / 8:4 / 5:7；不用 1:1（呆板） |
| 非对称 asymmetric | "太正了""像模板" | 两栏比例不等或错位对齐 | 至少 1 处；比例差 ≥15% |
| 出血 bleed | "图顶到边上" | 元素超出内容区边界 | 超出 24–48px |
| 首屏 above the fold | "一打开看到什么" | 不滚动即可见区域 | 桌面 1440×900 → 约 820px 高；移动 844 |
| 折叠线 fold | "第一屏之后" | 首屏与滚动区的分界 | 折叠线上必须有唯一焦点 |
| 粘性 sticky | "跟着滚""头一直在" | 元素滚动到阈值后固定 | 同容器只允许 1 个 `top:0` |
| 固定层 fixed | "浮着挡住 / 滚动被盖住 / 浮在上面" | 相对视口固定（吸底/浮标） | 必须给内容预留高度 + 安全区 |
| 抽屉 drawer | "从旁边滑出来" | 侧边滑入的面板 | 宽 320–400；遮罩 40% 黑；Esc 关闭 |
| 底部弹层 bottom sheet | "从下面弹出来" | 移动端底部上滑面板 | 高 40%/70%/90% 三档；圆角 20 顶部 |
| 卡片流 card grid | "一块一块的" | 等宽卡片按行列排布 | 2/3/4 列；卡间距 24；至少 1 张破格 |
| 瀑布流 masonry | "高低不齐那种" | 列宽相等、高度不等的排布 | 列间距 24；首卡可整宽破格 |
| Bento | "一大几小拼起来" | 不等宽网格拼图式布局 | 1 大 + 3–5 小；大块占 2 列 |
| 分屏叙事 split narrative | "左图右文滚动" | 一侧 sticky、一侧滚动 | 左 55% 图 / 右 45% 内容 |
| 空区域 negative space | "太空了 / 空得慌 / 没有留白" | 未放内容的区域 | 营销页 ≥35%；后台 ≥25% |

## B. 间距与几何

| 术语 | 用户可能怎么说 | 定义 | 落地参数 |
|---|---|---|---|
| 间距系统 spacing scale | "太挤了 / 挨太近 / 不透气 / 间距不统一" | 一套固定步进的距离值 | 4/8 基准：4 8 12 16 24 32 48 64 96 |
| 内边距 padding | "字贴边了" | 容器内壁到内容的距离 | 卡片 20–24；按钮 20（横向） |
| 外边距 margin | "块和块挨太近" | 元素外部间距 | 用 gap 优先；禁止负 margin 修距 |
| 间隙 gap | "两块之间空一点" | 网格/弹性子项间距 | 网格 24；按钮组 12 |
| 圆角 radius | "太方了 / 太圆了 / 太尖" | 角部圆弧半径 | 8 输入 / 12 卡片 / 20 弹层；≤3 档 |
| 描边 border | "加个框" | 1px 边界线 | 半透明：浅 `rgba(0,0,0,.06)`，深 `rgba(255,255,255,.10)` |
| 分割线 divider | "中间那条线" | 内容分区细线 | 1px；左右不与容器边相接（内缩 16） |
| 高度层次 elevation | "要浮起来" | 用阴影/明度表达层级 | 阴影 ≤3 档，带色不用纯黑 |
| 层级 z-index | "被盖住了" | 叠放顺序 | nav 30 > sticky 20 > 内容 1；弹层 50 |
| 视觉焦点 focal point | "没重点 / 不知道看哪 / 乱" | 一屏唯一被强调的元素 | 1 个；靠尺寸 > 对比 > 孤立 |

## C. 排版

| 术语 | 用户可能怎么说 | 定义 | 落地参数 |
|---|---|---|---|
| 字阶 type scale | "字号乱 / 大小不一" | 一组有比例关系的字号 | 1.25：13/16/20/25/31/39/49 |
| 字重 weight | "字太细/太粗" | 笔画粗细 | 只用 400/500/700 |
| 行高 leading | "字挤在一起 / 密密麻麻" | 行间距离 | 标题 1.1–1.25；正文 1.6–1.75 |
| 字距 tracking | "字太散/太挤" | 字与字的间距 | 展示级 -0.02~-0.04em；正文 0 |
| 行宽 measure | "一行太长 / 看着累 / 看不下去" | 单行字符数 | ≤75ch；中文 30–45 字 |
| 展示字体 display | "标题字体" | 承担语气的字体 | 衬线/几何无衬线；仅 ≥31px |
| 元信息 caption | "下面那行小字" | 辅助说明文字 | 12–13px；仍需 ≥4.5:1 |
| 截断 truncation | "太长了省略一下" | 超出容器时省略 | 单行 ellipsis；多行 `-webkit-line-clamp` |
| 折行 wrap | "字跑到外面了" | 超宽时换行 | 长英文/URL 用 `overflow-wrap:anywhere` |
| 等宽数字 tabular | "数字对不齐" | 数字等宽排列 | `font-variant-numeric:tabular-nums` |
| 中英混排 | "中文里夹英文很怪" | 中西文混排规则 | 分别声明字族；数字与单位间不加空格 |
| 孤行/寡行 widow | "最后一行只剩一个字" | 段落末尾的孤立短行 | 用 `text-wrap:pretty` 或调整行宽 |

## D. 色彩

| 术语 | 用户可能怎么说 | 定义 | 落地参数 |
|---|---|---|---|
| 主色 primary | "主题色" | 品牌主识别色 | 1 个；面积 ≤10%；白字 ≥4.5:1（深主色 L*28–38） |
| 强调色 accent | "太花 / 颜色太多 / 花里胡哨 / 点缀色" | 只用于需要被注意的一处 | ≤5% 面积；与主色不同色相 |
| 语义色 semantic | "红色代表错误那种" | 成功/警告/危险/信息 | 降饱和 8–12%；软底深字 |
| 中性阶 neutral ramp | "太土 / 发灰 / 颜色脏 / 灰色系" | 从白到黑的灰阶 | 11 档，带同一色相（暖 30°/冷 250°） |
| 对比度 contrast | "看不清 / 字太淡 / 颜色太浅 / 灰不溜秋" | 前景与背景的亮度比 | 正文 4.5:1；大字/UI 3:1 |
| 色温 temperature | "太冷/太暖" | 色相偏冷或偏暖 | 底带 2–4° 色温；不用 `#F5F5F5` 死灰 |
| 饱和度 saturation | "太艳/太脏" | 颜色纯度 | 主色 ≥60%；语义色 ≤70% |
| 遮罩 scrim | "字压在图上看不清" | 图文之间的半透明层 | 黑 40–60% 或白 60–80% |
| 深色模式 dark mode | "夜间模式" | 深底浅字的主题 | 底 `#0B–0E`；面 +6–8% 明度；禁纯黑纯白 |
| 色彩令牌 token | "颜色统一一下" | 语义化的颜色变量 | `--color-bg/surface/ink/...`；组件只消费语义层 |

## E. 组件

| 术语 | 用户可能怎么说 | 定义 | 落地参数 |
|---|---|---|---|
| 按钮 button | "那个能点的" | 触发动作的控件 | 3 种变体 × 5 态；高 ≥44px |
| 输入框 input | "填东西的地方" | 单行文本输入 | 高 44；字号 ≥16（防 iOS 缩放） |
| 选择器 select | "下拉选一个" | 从列表选一项 | 与 input 同高；键盘 ↑↓ 可选 |
| 开关 switch | "那种拨动的" | 二元即时生效开关 | 44×24；开=主色，关=中性 |
| 复选框 checkbox | "打勾的" | 多选 | 20×20；标签可点 |
| 标签 tag / 徽章 badge | "小标签" | 状态或分类的短标记 | 高 22–24；软底深字；一屏 ≤6 |
| 标签页 tabs | "上面几个切换" | 同层级内容切换 | 下划线（后台）/ 胶囊（移动） |
| 面包屑 breadcrumb | "路径那种" | 层级位置导航 | 首页 / 分类 / 详情；末项不可点 |
| 手风琴 accordion | "展开收起" | 折叠面板 | 展开 150–240ms；一次只开一个 |
| 气泡 popover | "点一下弹出个小框" | 附着在触发元素旁的浮层 | 8px 偏移；点外部关闭 |
| 提示 tooltip | "鼠标放上去有说明" | 悬浮解释 | 延迟 300ms；键盘聚焦也显示 |
| 弹窗 modal | "中间弹出来" | 阻断式对话框 | 宽 400–560；Esc/遮罩关闭；焦点捕获 |
| 吐司 toast | "右上角提示" | 非阻断的短提示 | 3s 自动消失；`aria-live` |
| 骨架屏 skeleton | "加载白屏 / 闪一下 / 加载时的灰块" | 内容占位 | 与真实内容同尺寸；1.5s 循环 |
| 空状态 empty state | "什么都没有 / 空白页 / 一条数据都没有" | 无数据时的引导 | 一句说明 + 一个主操作 |
| 分页 pagination | "翻页" | 长列表切页 | 每页 20–50；页码 ≤7 个 |

## F. 状态（每个可交互组件必须齐全）

| 状态 | 用户可能怎么说 | 定义 | 视觉差异（至少 2 项） |
|---|---|---|---|
| default | — | 静止态 | 基准 |
| hover | "鼠标放上去" | 指针悬停 | 底色 +4–6% / 抬升 1–2px |
| active | "按下去" | 按压瞬间 | `scale(.97)` + 阴影收 |
| focus-visible | "键盘选中" | 键盘聚焦 | 2px 环 + 2px 偏移 |
| disabled | "不能点" | 不可用 | 透明度 .45 + 禁手势 |
| loading | "点了没反应" | 处理中 | 文案淡出 + 进度 + 宽度锁定 |
| empty | "一条数据都没有" | 无内容 | 说明 + 主操作 |
| error | "报错了" | 失败 | 语义色 + 怎么修 |
| success | "成功了" | 完成 | 勾线 + 状态文案 |

## G. 交互与动效

| 术语 | 用户可能怎么说 | 定义 | 落地参数 |
|---|---|---|---|
| 微交互 micro-interaction | "有点反馈" | 小范围即时反馈 | 120–200ms；ease-out |
| 过渡 transition | "变化别太生硬" | 状态间的平滑变化 | 240–320ms |
| 转场 page transition | "换页别闪" | 页面/视图切换 | 320–480ms；shared axis |
| 编排 choreography | "一起出现有点乱" | 多元素按序入场 | stagger 40–80ms；总长 ≤420ms |
| 缓动 easing | "动得不自然" | 速度曲线 | `cubic-bezier(.22,1,.36,1)`；禁 linear |
| 弹性 spring | "有点回弹" | 物理弹簧 | 300/20；过冲 ≤10% |
| 视差 parallax | "滚动有层次" | 前后景不同速 | 位移 ≤视口 15% |
| 共享元素 shared element | "图放大到详情" | 跨视图延续同一元素 | FLIP 或 `view-transition-name` |
| 光标跟随 spotlight | "跟着鼠标的光" | 指针处高亮 | 仅 `hover:hover`；rAF 节流；移动端关闭 |
| 呼吸 breathing | "有点活着的感觉" | 低频缩放/明暗循环 | 3–8s；振幅 ≤3%；一屏 ≤2 个 |
| 降级 reduced-motion | "别动，晕" | 系统减少动效偏好 | 位移/循环归零，保留静态反馈 |

## 用法：三步翻译

```
1 抓症状   用户原话里的"挤/土/花/卡/没重点/挡住/点不到" → 对应 B/D/E 表的术语
2 定术语   说出术语 + 一句人话解释（"这是间距系统，不是'感觉'"）
3 给参数   直接落到右侧"落地参数"列，不问第二轮
```

**示例**
> 用户："底下那条黑杠挡住按钮了。"
> → 术语：**安全区（safe area）**。不是"位置不对"，是吸底元素没有预留 `env(safe-area-inset-bottom)`。
> → 修法：`padding-bottom: calc(12px + env(safe-area-inset-bottom))`。
