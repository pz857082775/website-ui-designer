# UI 界面模板库（Templates）

> 用途：用户说"不知道要什么样"时，从这里选一个**结构**，再按 §3 Design Spec 换皮。
> 每个模板给：骨架 ｜ 关键参数 ｜ 状态清单 ｜ 记忆点建议 ｜ 常见翻车。
> **选模板 ≠ 套模板**：结构可复用，配色/字体/记忆点必须重做。

---

## 1. 产品落地页（SaaS / 工具）

```
[导航 68px: logo + 3 链接 + 主CTA]
[HERO 7:5: 主张(49-56px) | 证据卡(shadow-3) + 双CTA + 3个真数字]
[规格条: 4 列细线 + 数字 + 口径]
[论证 8:4: 截图/演示/差异表 | 三步说明]
[客户证言: 引文 + 署名]
[深色 CTA 面板: 一句主张 + 大按钮]
[页脚]
```
- 参数：内容宽 1360；区块 96；hero 上 96 下 64
- 状态：导航 hover、按钮 5 态、表单（若有）8 态
- 记忆点：**一个动作演示**（如 diff 生成、数字跳动），只播一次
- 翻车：居中大标题 + 双按钮 + 三卡片墙（§9 第 3 条）

## 2. 品牌首页（叙事型）

```
[全幅视觉 or 大字主张]
[非对称图文 1.4fr : 1fr，图出血 48px]
[数据/时间线（真序列才编号）]
[作品/产品横滑]
[宣言：单列 60% 宽]
[联系：超大字号]
```
- 参数：区块 128；行宽 38ch；展示字 64–96
- 记忆点：排版手法（超大衬线 / 混排 / 竖排），不用动效堆
- 翻车：每段都 fade-up；装饰插画占位

## 3. 定价页

```
[H1 + 计费切换（月/年）]
[3 卡：中间推荐卡抬高 8px + 边框主色]
[功能对比表（行=能力，列=套餐）]
[FAQ 手风琴]
[底部 CTA]
```
- 参数：卡宽 320–360；推荐卡 scale(1.02)；表行高 52
- 状态：切换 180ms；推荐卡 hover 抬升 2px
- 记忆点：计费切换时价格**数字平滑过渡**（不是闪变），220ms
- 翻车：三卡完全同高同色（没有推荐位）；假折扣

## 4. 功能/解决方案页

```
[面包屑]
[H1 + 一句价值 + 主CTA]
[问题 → 方案 两栏对照]
[能力 Bento（1 大 + 4 小）]
[集成 logo 墙（灰度）]
[相关功能 3 卡]
```
- 记忆点：问题/方案的**对照划痕线**（中间一条 1px 虚线）
- 翻车：功能堆砌无优先级；logo 墙彩色跳眼

## 5. 文档 / 知识库首页

```
[搜索框（居中偏上，最大 640）]
[快速开始 3 卡]
[分类网格 2×4（图标 + 标题 + 条目数）]
[最近更新列表]
```
- 参数：正文 16/1.7；代码块等宽 13；侧栏 240
- 记忆点：搜索框聚焦时**下方结果即时展开**（不是跳页）
- 翻车：卡片里塞长描述；分类超过 8 个

## 6. 文章 / 博客详情

```
[标题 39-49 + 元信息（作者/日期/阅读时长）]
[封面图 16:9 出血]
[正文 68ch 单栏 + 侧边目录（sticky）]
[引用块 / 代码块 / 图片说明]
[作者卡 + 相关文章 3 条]
```
- 参数：正文 17–18/1.75；段间距 24；引用左侧 2px 主色
- 记忆点：目录当前项**下划线滑动**（180ms）
- 翻车：正文行宽 >75ch；全篇渐变标题

## 7. 案例研究

```
[客户名 + 一句话结果（大数字）]
[背景 / 做法 / 结果 三段]
[关键指标 3–4 个（带口径）]
[客户引文 + 头像]
[相关案例]
```
- 记忆点：结果数字**从 0 滚到目标**（800ms，一次性）
- 翻车：只有"提升了效率"没有数字；配图是 stock photo

## 8. 后台仪表盘（只读监控）

```
[侧栏 224：分组导航 + 当前项软底]
[顶栏 56：标题 + 时间范围 + 刷新]
[KPI 4：图标软底 + 标签 + 28px 数字 + 环比]
[主图（折线/柱）2fr | 次图（环形/榜）1fr]
[明细表（可排序、可筛选）]
```
- 参数：卡内 24；图高 280；表行 48
- 状态：加载骨架、空数据、错误重试、刷新中
- 记忆点：时间范围切换时**图表 morph**（240ms），不重绘闪白
- 翻车：8 个 KPI 同尺寸；图表无单位

## 9. 数据工作台（操作型）

```
[钩子条：一句结论 + 待处理数（可点）]
[待办列表（行=事项 + 状态 + 负责人）]
[侧栏：筛选 + 保存的视图]
[批量操作条（选中后浮出）]
```
- 规则：钩子必须有"今天要处理"的指向；**数据地板五问**必须过
- 记忆点：完成一项时**行折叠 + 计数递减**（150ms）
- 翻车：钩子是"共 1,284 条"（统计条不是钩子）

## 10. 列表 / 表格页

```
[标题 + 主操作]
[筛选行：搜索 + 3 chips + 高级筛选（折叠）]
[表格：表头 sticky / 行 hover / 选中态]
[分页 或 虚拟滚动]
```
- 参数：行高 48；数字右对齐等宽；空列不显示
- 状态：加载骨架（同列宽）、空态（清除筛选）、错误、无权限
- 记忆点：筛选后**结果数变化**在标题旁淡入（160ms）
- 翻车：每列都加边框；每行都放 3 个图标按钮

## 11. 详情页（商品 / 实体）

```
[左 8：主图 + 缩略图 | 右 4：标题/价格/规格/CTA（sticky）]
[参数表（定义列表）]
[图文详情]
[相关推荐 4 卡]
```
- 参数：图 4:3；右栏 360；CTA 常驻
- 记忆点：图片切换**缩放过渡**（220ms）而非硬切
- 翻车：CTA 随滚动消失；规格用下拉藏关键信息

## 12. 表单 / 多步向导

```
[步骤条（3–4 步，可回退）]
[单列表单（标签上、输入下，间距 16）]
[行内校验 + 顶部错误汇总]
[底部：上一步 / 下一步（sticky）]
```
- 参数：输入高 44；标签 13；错误文案 12；字段间距 20
- 状态：default/focus/error/success/disabled/loading
- 记忆点：步骤完成时**步骤条填充**（180ms）
- 翻车：一屏 20 个字段；错误只在提交后提示

## 13. 设置页

```
[左侧分类（6–8 项）| 右侧分组表单]
[每组：标题 + 说明 + 控件（开关/选择/输入）]
[危险区：独立分组 + 描边警示]
[保存条（有改动才出现）]
```
- 记忆点：改动后底部**保存条滑入**（200ms）
- 翻车：即时保存无反馈；危险操作与普通设置混排

## 14. 登录 / 注册

```
[左 5：品牌区（主张/图）| 右 5：表单卡]
[第三方登录（1–2 个）]
[邮箱/手机 + 密码 + 忘记密码]
[底部切换：有账号？登录]
```
- 参数：表单卡 400；输入 48；按钮全宽
- 状态：加载、错误（账号不存在/密码错）、锁定
- 记忆点：切换登录/注册时**卡片高度 morph**（240ms）
- 翻车：表单卡在满屏渐变上；错误信息用 toast 一闪而过

## 15. 搜索结果页

```
[搜索框（保留关键词）]
[结果统计 + 排序/筛选]
[结果列表（标题 + 摘要高亮 + 来源）]
[相关搜索 / 无结果建议]
```
- 记忆点：关键词**高亮块**（软底），不用彩色字
- 翻车：无结果只写"暂无数据"；分页没有总数

## 16. AI 助手 / 对话

```
[会话区（消息流：用户右、AI 左）]
[AI 消息：流式正文 + 来源 + 后续建议]
[思考轨迹（可折叠）]
[输入区：prompt bar（@来源 / 命令 / 发送）]
```
- 参数：正文 16/1.7；消息间 20；输入区 sticky 底部
- 状态：生成中（流式 + 停止按钮）、失败重试、无来源提示
- 记忆点：**思考轨迹展开**（220ms）+ 步骤逐条出现
- 翻车：把"推理中"做成一个 spinner；流式输出整段重渲染

## 17. 移动端列表（H5 / 小程序）

```
[导航（标题 + 胶囊避让 96rpx）]
[sticky 筛选区：搜索 + chips（合并为一个 sticky）]
[首卡破格（整宽）]
[2 列瀑布流]
[吸底操作 + 安全区]
```
- 参数：375 基准；行高 64；触控 ≥44；动效 ≤300ms
- 状态：骨架（同尺寸）、空态（一键清除筛选）、错误重试
- 记忆点：首卡的**产地/来源信息**（真实数据，非装饰）
- 翻车：搜索与筛选各自 sticky（互相遮挡）

## 18. 移动端详情（吸底 CTA）

```
[大图 4:3 + 返回浮标]
[标题 + 价格 + 标签]
[参数（定义列表）]
[图文详情]
[吸底：价格 + 主按钮（安全区）]
```
- 记忆点：滚动时**标题栏从大图渐变出现**（180ms）
- 翻车：吸底遮住最后一行内容（未预留 padding）

## 19. 个人中心

```
[头部：头像 72 + 昵称 + 状态标签]
[数据 3 列（关注/收藏/订单）]
[功能列表（图标 + 标签 + 箭头）]
[设置 / 退出]
```
- 记忆点：数字滚动一次（600ms），不做循环
- 翻车：头像用 `1fr` 撑满（高过文字一倍）；功能项 12 个平铺

## 20. 空状态 / 引导

```
[一句说明（发生了什么）]
[一个主操作（怎么继续）]
[可选：示意图形（线性、单色）]
```
- 规则：**禁止**只写"暂无数据"；必须给恢复路径
- 记忆点：主操作按钮**轻微呼吸**（仅此处，3s）
- 翻车：用大插画占满屏；空态里放两个同等按钮

## 21. 游戏 HUD

```
[顶部：状态条（血量/资源）+ 暂停]
[中部：战斗区（不放置常驻 UI）]
[底部：技能/操作（拇指区）]
[边角：小地图/任务（距边 ≥5%）]
```
- 参数：1080p 字号 ≥14；命中区 ≥屏高 6%；60fps
- 状态：受伤/增益/冷却/禁用（必须当帧反馈）
- 记忆点：关键事件**一次性高亮**（≤400ms），不做常驻闪烁
- 翻车：HUD 遮挡战斗区中心 60%；红绿作为唯一区分
