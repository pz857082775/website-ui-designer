## 角色
你是一位精通玻璃拟态（Glassmorphism）与 3D 视觉的前端专家，
已通读反 slop 规则：不会用居中三件套、图标卡片阵、紫蓝渐变凑数。

## 风格（按参考图解剖，5 行式）
把页面改成通透玻璃风格
让半透明面板悬浮在简洁背景上
搭配适度背景模糊 微亮边缘和轻柔阴影
玻璃效果集中在导航与控件
正文对比清晰 主要按钮容易识别

## 设计令牌（从参考图目测取样）
--bg:#0E1116;  --glass:rgba(255,255,255,.10);  --glass-line:rgba(255,255,255,.2);
--ink:#FFFFFF;  --ink-2:rgba(255,255,255,.7);
--radius-panel:16px;  --radius-pill:999px;
--shadow:0 8px 32px rgba(0,0,0,.12);
--blur:blur(20px);

## 页面结构（按参考图从左到右、从后到前）
1. 简洁深色背景：中央偏上一枚金属质感圆环 + 一块岩石的 3D 静物主视觉
   （CSS/SVG 绘制：圆环用渐变描边，岩石用噪点滤镜，允许跨面板边界）
2. 中央大玻璃面板（Hero）：
   - 左上 logo 位；右上胶囊按钮 "Get Started"（白底黑字，全页唯一实色按钮）
   - 面板内左：大标题 "Our Process."（白，700，48px+）
   - 面板内右：两张小玻璃卡（Research & Development / Set up Workflows），
     各带一行小字说明
   - 面板底部通栏卡：Launch & Optimize + 一段正文
3. 玻璃只用于：导航条、面板、控件；其余全部深色实底
4. 阴影轻、边缘微亮（1px 内描边），前后景深靠遮挡表现，不靠发光

## 排版硬规则
- 标题白色 700，正文白 70%，对比清晰
- 胶囊按钮（999px）是唯一高强调元素，全页一个
- 面板内边距 24-32px，间距 24px
- 禁止：渐变文字、彩色图标方块、emoji、第二套圆角体系

## 动效
- 面板入场：从 y:30 淡入，0.5s，power3.out，stagger 0.08
- 3D 主视觉 6s 无限 float（y:±10px，sine.inOut），reduced-motion 停止
- 只动 transform/opacity；无 scrub、无 scroll-jacking

## 输出
- 单文件 index.html，内联 CSS/JS，GSAP CDN，双击可开
- 375/768/1440 三档可用；移动端小面板堆叠为单列
- 附 3 行实现说明；不确定的 API 标出来，禁止编造

## 自检要求（生成后执行）
与参考图并排比对：布局骨架、视觉层级、留白节奏三项对齐；
玻璃面板透明度/blur/描边三项与参考图目测一致；
全页实色按钮只有一个。
